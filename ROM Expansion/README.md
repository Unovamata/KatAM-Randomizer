# ROM Expansion

Enemies, mini-bosses and copy abilities ported from *Kirby: Nightmare in Dream Land* into *Kirby & the Amazing Mirror*. `KatAMExpansion.cs` applies them. Every version of KatAM works (USA `B8KE`, European `B8KP`, Japanese revision 1 `B8KJ`), with the NiDL ROM of the same region: USA (`A7KE`), European (`A7KP`) or Japanese (`A7KJ`, *Hoshi no Kirby: Yume no Izumi Deluxe*). The NiDL ROMs hold the same data, the Japanese one's frame tables `0x3A8C` further and its descriptors at `0x08742DAC`, the European one's `0x23C7EC` further and at `0x0897B678`. NiDL addresses in these notes and the code are the USA ones.

European games show the enemies' English names in every language. Japanese games show none: their HP bar names (both languages of the name table, `0x08D2C394`) are images of katakana, with no English letters to compose names from. Their name copies are the USA's code, so they get the same patch, with empty names (else the bar shows another type's name, or garbage for type `0x44`).

## KatAM versions

The code is written against the KatAM decompilation, which builds the USA version. `build.sh` links it once per version: the USA build against `katam.elf`, the others against `versions/<version>.txt`, the same symbols' addresses in that version, found in its ROM by `find_symbols.py <katam decomp> <ROM> <symbols...>` (functions by their code with call targets and pointers masked, variables through the pointers in matched functions, and the rest by the shift of the nearest symbol found). The shift is only checked against the first bytes of the function, so check what it finds when it can't match a function by its code (Japan's `sub_08034E14` is `0x08034DD8`, found from the call in Mr. Frosty's code; the shift gave a similar function). The USA link also gets the decompilation's static functions the code calls (`--just-symbols` only takes global ones; `sub_0809D060`, the mini-boss defeat). Those tables also hold what `KatAMExpansion.cs` patches in each version (sprite tables, spawn and parameter tables, the hit flash branch, the HP bar name copies, the number of anims: 938 in the Japanese ROM, 939 in the others). When the code starts using a KatAM symbol the tables don't have, `build.sh` says so: rerun `find_symbols.py` with the full list for each version's ROM.

## How they fit in

KatAM treats object types `0x00`-`0x37` as enemies all over its code, and the only free one is `0x31`. So every ported enemy is type `0x31`, and the template's behavior byte picks which: high nibble = enemy (`NIDL_*` in `nidl.h`), low nibble = its variant. What the game reads per type is shared, so `nidl.c` handles it per enemy:

| Shared per type | How each enemy gets its own |
|---|---|
| Animations (`AnimInfo` table, indexed by the object's frame) | One table holding every enemy's frames; each enemy has its own range (`animBase`) and anim ID |
| Palette key | The type has none; each enemy loads its palette with its anim ID as the key |
| Hurt frames (indexes 0 and 1) | A generic 32x32 frame drawn from the last 16 tiles of the object's VRAM, where each enemy uploads its own hurt frame |
| HP bar name | The game's two name copies (`0x08034ED2`, `0x08035B34`) are patched to call `NidlCopyName` |
| Behavior start after a hit | `NidlStart` calls the enemy's own start |
| Gravity | The engine pulls every enemy down unless flag `0x40` is set (KatAM's flying enemies set it); `NidlStart` sets it, and each enemy moves up and down like in NiDL (`NidlFall` is the engine's gravity, for the ones that just stand or walk) |

Mini-bosses work the same way on object types `0x40`-`0x42` (`OBJ_EMPTY_40`-`42`), which KatAM already treats as mini-bosses everywhere (they're in every `ObjType38To42` check, and `gUnk_08352D80[type - 0x38]` is the mini-boss music): see Mini-bosses below.

The hit flash also looked the palette up again by type when it ended; its branch at `0x080857EE` is patched to keep the enemy's palette (which is what it found for the game's own enemies anyway).

- `nidl_boss.c`, `bosses/*.c`: the bosses (type `0x43`): creation, the start of the fight, the mirror shard they leave, and one file per boss (see Bosses). What Kirby inhales in their fights is an enemy (type `0x31`, hidden from the randomizer's options): Whispy Woods' apples (`enemies/apple.c`), Mr. Shine's falling stars (`enemies/star.c`), Paint Roller's paintings (`enemies/painting.c`); and the star King Dedede spits swallowed Kirbys out in (`enemies/spit_star.c`).

- `build.sh /path/to/katam`: compiles everything with the decompilation's `agbcc`, links it at `0x09000000` for each KatAM version and writes `../KatAMExpansionCode.cs` (each version's code, the symbols `KatAMExpansion.cs` uses and what it patches).
- `find_symbols.py`, `versions/*.txt`: the KatAM symbols' addresses in each version (see above).
- `title.c`, `title.h`: Nightmare in Dream Land's title screen swarm (see Title screen below).

It needs only itself: without a NiDL ROM, the option pads the ROM and copies the expansion's code in, and allocates its trampolines in `gNidlCalmTrampolines`.
- `skip.c`: the randomizer's Skip the Tutorial option: `sbClearFunctions[1]` (`sbWorldPropsClear`, which `ClearSaveBuffer` runs after zeroing a blank, erased or unreadable file's world props: a new save) points to `NidlSkipClear` (`KatAMExpansionCalm.cs`), which runs it, then sets `gAIKirbyState` to `AI_KIRBY_STATE_NORMAL` (what the game sets once the cutscene after the tutorial ends: a new game then starts in Central Circle, `sub_080332BC`, and respawns there, `sub_08002C98`) and gives the tutorial's big chest's item as opening it would (room 0x325's chest, its template's item and treasure index as the randomizer left them, in `gNidlSkip`: a map, a spray, music, an HP up, or a mirror shard through its index 0x80 + n; its index marked, so the collection counts it). The demos clear too and set the state themselves. A file no clear touched (saved by a ROM without the option, or mid-tutorial) is caught at the single-player start, which a new and a continued game both run (`sub_08123FD4`, detoured to `NidlSkipStart`, its trampoline in `gNidlSkipTrampolines`): below 300 the state is set, the chest's item given unless its index is marked, and the file saved, before the start picks the room and spot (`sub_08002C98`: at 300, Central Circle's continue spot; room 0x321's mirror cutscene and room 0x323's intro skip themselves). Multiplayer starts elsewhere (`sub_080329C8`). It needs only itself, as `calm.c`.
- `warpstar.c`: the ported warp stars' rides (`KatAMExpansionRooms.cs`, `WarpFlights()`, `WarpRideDetours()`): four of KatAM's routines detoured to it, their trampolines in `gNidlRideTrampolines`, and the riding star's task swapped. The warp star's rev (`sub_0800C270`: KatAM's star waits 300 frames for the helpers with Kirby on it) is skipped for a ported star (subtype 6 and after), as NiDL's is off at once; the Power Orb's waits, but only until every Kirby in its room (not knocked out) is on it (`finale.c`'s `NidlFinaleAllAboard()`, the star's riders in its `+0xB5`). The Power Orb's star's flight starts with a step marked `0xFC` (`NIDL_RIDE_FINALE`): `NidlRideStep` holds Kirby there (no step run, no speed; hidden, `0x400`, when `PowerOrbRideSize()` says so) while `bosses/power_orb.c` moves him, and a step whose `+0xA` is `0xFFFF` (`NIDL_RIDE_ASK`) takes its size from `PowerOrbRideSize()` (the star's flag `0x400` hides it). A flight's room change (`sub_08055D9C`, a step flagged `0x40`: KatAM's flights change room once, to the star's room) on a step marked `0xFE` takes Kirby to the room in the step's `+0xA`, at the cell in its `+0` and `+2`, so a ride goes through several rooms. A flight's step (`sub_080534D0`): a ride's end step marked `0xFD` (not `0x80`) ends the flight where Kirby stands after his tumble, as KatAM's hop-off leaves him (the flight's flags off, facing the step's way), without KatAM's hop. Kirby's drawing (`sub_0803F46C`) and the star he rides (`sub_0808EEF4`, the task `sub_0808EDB8` starts: its one pointer becomes `NidlRideStar`, as its first instructions keep `gCurTask` in `r3`, which a detour's jump back would need): where a ride's step has a size (its `+0xA`, NiDL's matrix value, 256 / the size), the OAM pieces they just drew (`gUnk_030031C0`, from the count `gUnk_030024F0` had) become affine at that size around the star's middle (Kirby's spot), each moved in toward it, as NiDL draws them; matrices 7, 15, 23 and 31 (`gOamBuffer`), by the pieces' flips (KatAM's own sprites use matrix 0 only).
- `finale.c`, `ending.c`: the Fountain of Dreams finale's glue (the Power Orb's warp star, the flights out of Nightmare's room) and NiDL's ending down from the moon (see Bosses, Nightmare).
- `unlock.c`: the randomizer's Unlock the Ability Room option: Central Circle's door to the ability room (0x3CA; the NiDL hub has a copy) is a hub mirror object (`0x8C`, `special_hub_mirror.c`) of world slot `0x12`, hidden under its wall until that slot is set (KatAM sets it once the 15 big switches are pressed: `WorldMapUnlockMain`, then the door's scene). The hub mirror's init (`SpecialHubMirrorInit`, its address in `CreateSpecialHubMirror`'s literal pool) becomes `NidlHubMirrorInit` (`KatAMExpansionCalm.cs`), which sets slot `0x12` for that door, then runs the original (kept in `gNidlUnlock`). It needs only itself, as `calm.c`.
- `mirra.c`: Mirras (object `0x34`) fall, and open their door where they are: KatAM turns the engine's gravity off for a Mirra (its start, `sub_080B1174`: flags `0x40`, and `0x800`, which keeps it from moving at all), so one stood in the air once what it stood on broke, and opened its door (`sub_080B11C0`: the special block record of its template's cell) where it started. The Mirra's spawn becomes `NidlCreateMirra` (the original's address in `gNidlMirra`), which clears both flags after KatAM's `CreateMirra`; `sub_080B11C0` jumps to `NidlMirraOpen` (`KatAMExpansion.cs`, with the spawn table), which marks its encounter as KatAM's does and opens the door of the cell the Mirra is in, or of the first cell below it with one (where it's falling; nothing solid between, cells read through `GetCollisionTile`, which the bigger rooms replace), else its template's cell's: a door is a block record of the cell as it is now whose new value is a door record's of the same cell (`MirraDoor()`). KatAM's own Mirras stand on solid ground, so theirs stays KatAM's door. Installed with the ROM Expansion (`AddEnemies()`).
- `chest.c`: mirror shards in chests: a chest's opening (`sub_0800AFC8`) is detoured to it (`KatAMExpansionChests.cs`). A chest holding item `0x40 + n` (an id KatAM doesn't use) collects shard n, saves, and spawns the shard object (`0x65`, subtype n, made as the bosses make theirs) 24 pixels above itself, which runs the game's own shard pickup (cutscene `n + 1`, then the Dimension Mirror room); opened once shard n is owned (a boss's, the field's, another chest's), it spawns a Maxim Tomato there instead (KatAM's own tomato object, as an owned field shard is one); other chests run the original (its trampoline in `gNidlChestTrampolines`). The randomizer gives each of these chests a treasure index of its own, `0x88 + k` (16 at most): `HasChest` reads past `gTreasures.chestFields` into `shardField`'s bits 8-23 there, which nothing else uses (`NumShardsCollected` counts bits 0-7, `NumChestsCollected` the first 0x80), and opening one marks it, so a chest shows open once it's been opened, and only then. They're left out of the rooms' 1E8 chest lists (`sub_08002B30`, which would loop forever looking for them, isn't called). The shards the randomizer puts in rooms instead (the option off) spawn through `NidlCreateShard` (object `0x65`'s spawn table entry, `OwnedFieldShards()`): a room's own shard (its template in the ROM, subtype under 8) already owned is a Maxim Tomato made from its template as `CreateBonus` makes a room's food (so it's gone once eaten until the room is entered again); the shards the game makes as it goes (a boss's, a chest's, a NiDL boss room's way out) and the Dimension Mirror stay shards. Bosses Give Random Shards (`RandomizeBossShards()`): each of KatAM's boss defeats (`gUnk_08350E58`'s handlers) asks `HasShard` about its shard as a constant right before the call (`movs r0, #n; bl HasShard`, 9 sites with King Golem's harder rematch), each constant becomes the boss's new shard; the shard the boss makes in its room (its template's subtype the game's) is made as the game's, then given the new number (`unkD4`, `unk83`) from `gNidlShard.bossShards`, the template keeping the game's, which places the victory dance (`gUnk_08352DBE`) in that room; the pause screen's `gAreaMapRoomIdsAndShards` takes the new numbers; the NiDL bosses' templates (types `0x43`, `0x44`) take theirs in their behavior's low nibble. Like `calm.c`, it needs only itself.
- `rooms.c`: rooms bigger than KatAM's 1950 blocks (see Rooms below: Limits), the game's room loader and collision functions with bigger buffers.
- `../KatAMExpansionRooms.cs`: NiDL's rooms (see Rooms below).

## What `KatAMExpansion.AddEnemies()` writes into the KatAM ROM

The ROM is first padded from 16 MB to 32 MB with `0xFF` (the most the GBA maps: `0x08000000`-`0x09FFFFFF`, which emulators and flash carts load like any other ROM; the game saves to SRAM, so nothing else depends on its size). Everything new goes in that second half, so the expansion has 16 MB for its enemies and leaves the game's own free space to the randomizer.


| Where | What |
|---|---|
| `0x1000000` | Code, then the converted graphics, animations, names and the extended sprite tables |
| `gSpriteTables` (`0x3B909C`) | `anims`, `attrs` and `oamData` copied with more entries: anim `939` is the hurt frame, `940` on are the enemies (one variant per frame) |
| `gSpawnFuncTable1[0x31]` | `CreateNidlEnemy` |
| Object parameters (`0x351648 + 0x31 * 0x18`) | Hurt frames 0 and 1, Waddle Dee's score and HP, no ability, no palette key, VRAM for the biggest frame plus the hurt frame, `NidlStart`, the shared animations |
| `0x08034ED2`, `0x08035B34`, `0x080857EE` | The patches above |

Each enemy's HP is its own (`sNidlEnemies`, set at spawn), as KatAM's enemies': 4 for the ones that give an ability (as KatAM's Sword Knight, Hot Head or Sparky), 2 for the others. NiDL's are 1 or 2, so anything killed them in one hit.

Graphics come from the player's NiDL ROM: each enemy's descriptor (`0x0873EEA0 + (type - 8) * 4`: palette, LZ77 tiles) and frame table (8-byte OAM records). Nothing from NiDL is shipped.

## Mini-bosses

Ported mini-bosses are object types `0x40`-`0x42`; the behavior byte's high nibble picks the mini-boss (`NIDL_POPPY_BROS_SR`... in `nidl.h`), the low nibble its variant. An object's frame index is a byte, and the mini-bosses have more than 256 frames together, so they're spread over the three types, each with its own `AnimInfo` table (`0x40`: Poppy Bros. Sr., Mr. Tick-Tock, Grand Wheelie; `0x41`: Bugzzy, Fire Lion; `0x42`: the Meta-Knights); a mini-boss created with the other type's number becomes that type's first. KatAM's own Mr. Frosty, Bonkers and Phan Phan stay as they are (NiDL's are the same mini-bosses).

- **The fight** starts like KatAM's mini-bosses' (Mr. Frosty, `0x080CB7E8`): the mini-boss waits facing Kirby, untouchable, until Kirby is in the template's area (`unk1A`-`unk20`, the randomizer keeps the vanilla mini-boss's, or makes it the whole room for an enemy's spot, so the camera doesn't lock there), then the camera stays in that area (`Macro_081003EC`, which also copies its bounds into `unkA4`-`unkAA`; every frame `NidlUpdate` keeps the mini-boss's x inside them with `ObjXSomething`, as KatAM's mini-bosses do, and the Meta-Knights get Meta Knight's), the HP bar shows and the mini-boss music plays (`Macro_08100F18`). Defeat is KatAM's (the engine handles every type `0x38`-`0x52` the same way: it flies off, shows the frame after its second hurt frame, and explodes); its blink animation table (`gUnk_08D610B4`, by type - `0x38`) only had types `0x38`-`0x3F`, so it's copied with entries for `0x40`-`0x42` (none) and its one use points at the copy.
- **Shared per type**, as for the enemies: one `AnimInfo` table (its own, after the enemies'), each mini-boss's own palettes and anim ID, a 64x96 hurt frame (a 64x64 and a 64x32 piece, 96 tiles at the end of the object's VRAM, origin at its center; anim indexes 0, 1 and 2; type `0x42`'s is 32x64, 32 tiles, as several knights are out at once). A mini-boss can have several hurt frames (`NidlObject.hurt` picks one: each knight its own). A mini-boss too tall for it (Fire Lion) has its hurt frame and every frame drawn some pixels lower (`hurtShift`), and its hitbox and floor box as much lower (the engine resets `objBase55` after every frame it draws, so the sprite can't be moved back up), its own HP bar name. Each mini-boss starts on the floor under the cell NiDL puts it in (`NidlOnFloor`, nidl.h: its box's bottom on that cell's bottom; the enemies' snap, to the cell edge under the box's bottom, put Bugzzy, Mr. Tick-Tock and Fire Lion, whose boxes reach past 23 pixels, a cell lower: in the ground, or through a floor a cell thick, as in rooms 0x2EF and 0x135). Every ported object's task ends in `NidlDestroy`, which empties the HP bar and lets go of the object if the HUD shows it (the HUD only lets go once the object's flags say it's gone, `0x0803533C`, and by then its memory can hold another object: the bar stayed after the enemy died). `NidlMinibossStart` (the type's start, after a hit too) sets the mini-boss's ability and calls its own start once the fight has started.
- **Graphics**: NiDL's mini-boss descriptors are at `0x0873F0E4 + index * 4` (USA; `region.Descriptors + 0x244` in every region; index = NiDL type - `0x31`), in the enemies' format, often with two palettes: frames drawn with the second load it under the anim ID | `0x2000`. Frame tables are the `0x0875xxxx` literal each spawn function stores at `obj+0x38`. Some frames are *streamed* (Mr. Tick-Tock's body): the table entry points to 12 bytes instead of OAM records, pointers to the frame's OAM records, its own palette (`u16 0x20`, then 16 colors) and its own tiles, which NiDL uploads with the frame (rows of VRAM, 32 tiles each: `u16` byte count and the tiles, until `0xFFFF`); `KatAMExpansion.PartPieces` reads both kinds.
- **Object types `0x40`-`0x42`'s parameters** are Mr. Frosty's (score, HP), with the hurt frames, no palette key, VRAM for the type's biggest frame plus the hurt frame, `NidlMinibossStart` and the type's animations; `gSpawnFuncTable1[0x40]`-`[0x42]` are `CreateNidlMiniboss`.
- **HP bar**: its fill is HP times `gUnk_08351458[type - 0x38][players - 1]` (the table right before `gUnk_08351648`), >> 8 (64 is full); KatAM has a placeholder (8192) for types `0x40`-`0x44`, which made the bar garbage, so the mini-boss types get Mr. Frosty's 546 (30 HP, as every ported mini-boss has).
- **Projectiles** (Poppy Bros. Sr.'s bombs, Mr. Tick-Tock's notes, Fire Lion's flames, the knights' axes, javelins and tridents) are attack objects, which KatAM's inhale doesn't take (it inhales objects only). `NidlInhaled()` (nidl.c) inhales them as KatAM's enemies are (`object.c`'s `0x0809C380` and `0x0809C48C`): once one is in a Kirby's inhale (KatAM's box, `0x08071FC0`: 4 to 48 pixels ahead, 18 up to 16 down, while he inhales: animations `0x1A`, `0x1B`, `0x6A`, `0x6B`) it's pulled in, harmless, faster and faster, and becomes a mouthful that gives nothing (`NidlSwallow`), for him to spit back as a star (what he fights the mini-boss with when he has no ability); if he stops inhaling first, it's gone in a puff. Not inhaled: Mr. Tick-Tock's rings (they're around it as it rings) and the Mace Knight's mace (on its chain).
- **Map tracker**: `KatAMExpansion.WriteMapTable` writes the last `0x100` bytes of the ROM: `NIDLMAP` and a version byte (1), then per mini-boss its type, index, name and an icon (its `Icon` frames, as 16-bit colors), which the map tracker reads to tell an expanded ROM and show these mini-bosses (`KatAM Map Tracker/Core/RomMap.cs`).
- **Randomizer**: with "Include Mini-Bosses" (ROM Expansion tab), types `0x40`-`0x42` join the mini-boss pool once per ported mini-boss of theirs, the behavior picking a mini-boss and then one of its variants.

## Bosses

Ported bosses are object type `0x43` (and `0x44` once `0x43`'s 256 frames are full: Paint Roller, Heavy Mole, King Dedede and both of Nightmare's, under 256 frames together: King Dedede keeps only the frames he uses; `OBJ_EMPTY_43`, which KatAM already treats as a boss everywhere: `ObjType43To4D`, the boss music `gUnk_08352D80[type - 0x38]`, a hit only flashes it, and its defeat: it freezes, explodes and goes, `sub_08088528`, then runs `gUnk_08350E58[type - 0x43]`, KatAM's bosses' shard handlers, NULL for `0x43` until `KatAMExpansion.cs` makes it `NidlBossDefeat`). The behavior byte's high nibble picks the boss (`NIDL_WHISPY_WOODS`... in `nidl.h`), its low nibble is the mirror shard it leaves: its NiDL level's (0-7). The graphics are built as the mini-bosses' (one `AnimInfo` table for the type, the 64x96 hurt frame), the type's parameters are Kracko's (`0x45`) with the bosses' functions, and its HP bar fill is Kracko's for one player (273: 60 HP, as KatAM's bosses).

- **NiDL's bosses** are room objects of category 2 (0 King Dedede, 1 Paint Roller, 2 Meta Knight, 3 Heavy Mole, 4 Mr. Shine & Mr. Bright, 5 Whispy Woods, 6 Kracko, 7 and 8 Nightmare; NiDL types `0x3B`-`0x43`, spawns in the type table `0x0872FF34 + type * 8`), in their levels' last stage (the boss rooms, ported with the levels). Their graphics descriptors follow the mini-bosses' (mini-boss descriptors 30-38, boss index + 30), and their frame tables are each spawn's `+0x38` literal. `KatAMExpansionRooms.RoomBosses` maps the ported ones: a boss is created where NiDL's spawn puts it, with an arena (`enemies/arena.c`) holding the camera on its screen and the room's doors shut until it's beaten, as a mini-boss fight's; a boss's screen may reach the room's hidden rows, down to where KatAM's camera stops (its floor shows). Each fight's area holds a CPU helpers' zone point (`BuildNavigation`): a called helper looks for one inside the camera's bounds (`sub_08010034`) and, with none there, never stops looking (the game froze as Heavy Mole's fight started); a helper off the screen looks for one he has a way to, so every room's zones are joined (groups apart, blocks without a floor between them, linked by their nearest two: Kracko's tower froze the game as its camera locked at the top with the helpers below).

Its defeat is KatAM's; then `NidlBossDefeat` puts its mirror shard (`0x65`, subtype the shard, made as KatAM's bosses make theirs) in the middle of the screen, which Kirby takes as a boss's (the shard cutscene, the shard flying to the Dimension Mirror), or a Maxim Tomato when that shard is owned already (as KatAM's bosses fought again).

In the European NiDL ROM the frame tables from `0x08753E3C` on (Mr. Shine & Mr. Bright's, Whispy Woods', Kracko's...) are moved further than the others (`0x23CA5C`, `LateShift`).

In water, every ability's B button does what KatAM's other abilities do (the base ability's entry). CPU helpers fight like Normal Kirby.

How they fit in:

- **Ability field.** KatAM keeps the ability Kirby is getting in 5 bits of `transitioningAbility`, with 3 flags above it, so 27-31 were all the room there was. It's widened to 6 bits:
  - the "random" flag moves from `0x20` to `0x40`;
  - the old `0x40` flag ("several things in the mouth", which makes the spat star bigger) moves to `unkF1`, which the game only ever clears;
  - every `& 0x1F` read of the field becomes `& 0x3F` (18 places, found by their code, the same in every version);
  - swallowing (`sub_080547C4`) is replaced by `NidlSwallow`.
- **Ability tables.** Every table KatAM indexes by ability (B on land and in water, setup, body palette, hats, the CPU helpers' AI, the state after getting an ability, the pause world map's Kirby) is copied with 34 entries, and the game's code is pointed to the copies. The new entries come from `gNidlAbilityTables`, or from Normal's.
- **Swallowing.** `sub_080547C4` took abilities `0x1B` and `0x1C` to mean "random" and "none". They're now `0x3B` and `0x3C` (`NIDL_SWALLOW_*`), and the one object type whose ability was `0x1B` (`0xCE`) is changed to match.
- **HUD and pause portraits** are NiDL's ability cards. `sub_080356AC` and `sub_08088640` are detoured to `NidlAbilityPortrait` and `NidlAbilityHudTimer`, and the special portraits (`0x1C`-`0x1F`) move to `0x2C`-`0x2F`.
- **Hats** (`KatAMExpansionHats.cs`). KatAM draws Kirby as a body plus a hat sprite, animating in step. The new abilities use Normal's body table (`gUnk_0834C5D4`), and each one's hat anim has a variant per entry of it (185): the body's commands, with NiDL's hat for the same pose.
  - `BodyMatches` pairs each KatAM body frame with one of NiDL's plain Kirby poses, by silhouette, checked by eye. Mirrored body frames (attributes `| 0x4000` / `| 0x8000`) are matched unmirrored, and their hat is mirrored the same way.
  - `HatFrames` pairs each plain pose with the same pose in the ability's block. Its body pixels match exactly, or match outside the hat where the hat hides part of it.
  - Poses with no match (inhaling, a mouthful, Kirby facing the camera with something on his head) get no hat.
  - NiDL's Kirby is always pink, so its hats (Needle's) draw some of his head in his colors. Those pixels are left to the body sprite, which has the player's colors, where KatAM's body frame covers them (`BodyCoverage()`: the body frame drawn from its attributes, OAM entries and the tiles its GetTiles loads, mirrored as KatAM mirrors it). Where it doesn't (KatAM's Kirby is shaped a little differently), they're drawn in the hat's nearest other color: the room showed through Needle's spikes. Body frames whose hats come out the same share one frame.
  - Calling the helpers (animation indexes 97-99: taking out the phone, dialing, ringing; `CallAnimations`) shows no hat: it looked odd on Kirby holding his phone.
- **Attack poses** (`KatAMExpansionMotions.cs`) are NiDL's frames, played at animation indexes `0x4A`-`0x59` (copy abilities' own), which `NidlAbilitySetup` points to them.
  - Kirby's own pixels go to the body sprite, which has the player's palette and 16 tiles of VRAM.
  - The rest (ice, needles, the cape) goes to the hat sprite, which has 48 tiles of VRAM. Frames are cut into 8x8 cells on the grid (of the 64 offsets) needing the fewest: Needle's spiked ball in the air needs 50 on the top left's, which lost its bottom, and 48 on its best. The cells are drawn in OAM pieces as big as they can be (each piece's cells all with pixels, the biggest shapes first): the same tiles in fewer pieces, as KatAM's `DisplaySprite` takes its time per piece and NiDL's frames on four Kirbys made dozens each.
  - KatAM loads the hat sprite's palette from the ability's hat, so the poses use the colors that palette has free. Needle's hat leaves few, so its needles are a duller yellow than NiDL's.
- **Attacks** (`NidlAttackCreate`) are Burning's attack box: an object following Kirby while he's in the ability's state, with the hit's kind (`unk68`, as in `gUnk_082DDFC8`) and strength.

## Rooms

The rules every door, mirror, hub and transport follows are in [Map and Door Design Rules](../Documentation/Map%20and%20Door%20Design%20Rules.md): read them before changing how the map is laid out.

NiDL's level rooms (275, each one KatAM room) are converted from the player's NiDL ROM into KatAM's free room slots (rooms whose `gRoomProps` entry is all `0xFFFF`, ascending from 1), by `KatAMExpansionRooms.cs`, after the enemies and abilities ("Include Rooms"). `KatAMExpansion.PortedRooms` lists which NiDL room became which KatAM room, `PortedDoors` their doors. Left out: the levels' hub lists (hub, museum, arena, boss tower, boss room: no gameplay of their own), level 7's stage 1 (the boss rush's copies of the boss rooms) and stage 2 (11 unused test rooms), the 7 placeholder 2x2 hub entries, and 3 empty 16x11 floors no exit leads to (levels 2 and 3's stage 5: `(2,5,6)`, `(3,5,2)`, `(3,5,6)`). The boss arenas (each level's last stage) and the Fountain of Dreams are kept, for the bosses to come.

- **NiDL's rooms** (the same data in every region, only the table moves: USA `0x087E1D58`, Japan `0x087E60DC`, Europe `0x08BFD8E8`): per level (0-7), 8 stage lists (`table + level * 0x20 + stage * 4`), then the levels' hub lists (`table + 0x100 + level * 4`: hub, museum, arena, boss tower, boss room). Each list holds room records (null where a room is missing) until one whose index (`+2`) isn't its place. A record: `+8` the cells (LZ77, `u32` per 16x16 cell: metatile, attribute, whose high byte is the collision), `+0xC` the breakable blocks' numbers (LZ77, `u16` per cell), `+0x10` the object data (a `u32` per block number: the cell it leaves when broken, metatile and collision as the cells', until `0xFFFFFFFF`: mostly air, sometimes a wall, a floor, a ladder, water or the block again, which stays), `+0x14` width, height (cells), `+0x18` the foreground (palette: `u16` byte count, then the colors, loaded at palette 2; LZ77 tiles at `0x06004000`; LZ77 metatiles, 4 tilemap entries each), `+0x28` the background (palette loaded at palette 8; LZ77 tiles; the map: `u16` byte count, width, height, then `0xFFFF` and the LZ77 map in GBA screen block order (32x32 blocks, left to right, then top to bottom: 64x48 for the Fountain of Dreams'), or the map row by row), `+0x34` the background's scroll rates (x, y, 16ths), `+0x44` the exits (12 bytes: room, 0, door x, y in cells, landing x, y), `+0x48` the objects (8 bytes: category + 1, index, variant, flags, x, y) up to the record itself, `+0x50` where Kirby starts.
- **Collision**: the high nibble is the kind (0, 5, 7 solid; 1 one-way floors, `0x10` a door; 2 breakable blocks; 3 ladders and climbing walls; 4 air currents; 6 spikes; 8 and C water; 9 water with one-way floors; E spikes in water), the low nibble the shape in NiDL's height maps (`0x087328F0`: empty, full, 45° and gentle floors, ceilings). `RoomCollision` maps each value to KatAM's (`gCollisionAttributes`): full `0x0D`, floors `0x0B`/`0x0C` (45°) and `0x05`-`0x08`, ceilings `0x01`-`0x04`, `0x09`, `0x0A`, thin floors Kirby drops through with Down as in NiDL (`0x0E`, slopes `0x10`-`0x13`, `0x18`, `0x19`: KatAM's own one-way `0x0F`, `0x14`-`0x17`, `0x1A`, `0x1B` don't let him, so a way on down through one would be shut, as in Orange Ocean 3-2; but a room where, from each place Kirby arrives, dropping through leads to no door, warp star or cannon he doesn't reach from there anyway gets KatAM's (`ThinFloors()`, each arrival on its own: from all of them at once, a door one reaches counted for all, and Yogurt Yard's 0x23E shut its only way on down; Rainbow Resort's 0x304, where a bomb dropped Kirby through its platform), ladders (NiDL's top `0x31` KatAM's top `0x20`, a ledge Kirby stands on and climbs down from, its body `0x30` `0x21`: swapped, Kirby fell through the top and climbed on past it), spikes `0x1C`, water `0x48` and its slopes `0x34`-`0x43`, spikes in water `0x6D`. Breakable blocks become KatAM's special blocks (the solidity map's list: kind 1, value, x, y, the 4 tilemap entries left after, the collision left: NiDL's, from what the block leaves): star blocks `0xF0` (NiDL `0x24`; Rainbow Resort's few `0x20`), bomb blocks `0xF1` (`0x2E`), the blocks they set off `0xF2` (`0x2D`: touching the bomb block and each other, which KatAM breaks as a chain) and `0x2F` (NiDL's grey metal blocks) KatAM's silver metal blocks `0xF5` (as room 0x134's), which only some abilities break, as KatAM's own (tested: Hammer, Burning, Fighter, Wheel, Missile, Master, Smash's forward+B, and Stone from above; Throw with something held, by the owner; not Beam, Laser, Fire, Ice, Spark, Parasol, Sword, Cutter, Cupid or Bomb) (its `0xF4` blocks break with any ability's attack); a room with more than `MetalBlocks` (64) of them is Heavy Mole's dirt, which any attack digs through: star blocks. The door planner counts metal blocks as walls (`OpenCell()`), so no room needs an ability to be reached; what they guard is optional. NiDL's `0x34` is a thin floor too (clouds and bridges: Grape Garden's boss tower), but where a group of them touches a breakable block they're blocks a bomb block sets off (Ice Cream Island's sand path in stage 2, room 0xEF: it was solid, a softlock). NiDL's `0x35` cells touching a chain (and the `0x34` cells among them) are its invisible links: the chain goes on through them, as KatAM's own `0xF3` (not solid, with the chain attribute `0x40` that `code_0800E0E4.c` follows from block to block; each with a special block record that leaves the cell as it was), so one bomb block sets off all NiDL links to it (Rainbow Resort 3-4's ceiling and pits, 0x2FD; 3-7's goal door from the bottom, 0x304). Bomb blocks are only where NiDL has them (Kirby coming in on a chain's far side leaves by the two-way door he came through); a chain whose bomb block starts broken (a door lands Kirby there, 0x27C) or that has none is star blocks. Shotzos standing on breakable blocks are kept (NiDL's fall when the blocks go; KatAM's go with them), as 0x2FD's cannons under its ceiling. Air currents are plain air for now.
- **Graphics**: the foreground tiles are NiDL's own LZ77 (it decompresses them to VRAM too), at KatAM's `0x06008000`; its palettes 2-7 are KatAM's 0-5, so every tilemap entry's palette goes down by 2; the metatiles become KatAM's 8x8 tilemap (LZ77). ## Title screen

With "Random Title Screen: KatAM's Intro or NiDL's Kirby Swarm", the seed picks KatAM's intro or NiDL's title animation (`KatAMExpansionTitle.cs`, `title.c`).

- **The NiDL enemies in KatAM's intro parade** (Random Intro Parade, `KatAMTitleScreen.AddNidlTypes`): the parade's two type tables (`gUnk_08387348`, 0x10 bytes a type: palette slot, lift, width, update; `gUnk_08D62530`, 6 bytes: anim, variant, tiles; 70 types each) move to the free space with a type more per enemy in `ParadeLoops` (types 0x46 on: Twizzy, Bubbles, Starman, Needlous, Blade Knight, Cool Spook, Gip), the intro's pointers to them (its literal pools) changed. Each new type is a plain walker (type 0x0C's update), its own palette slot, as wide as its widest frame, lifted from the parade's line by its frames' lowest point (height - origin's y); its sprite is an extra variant of the enemy's anim, after its frames: its NiDL walk or flight as its C code plays it (each step's GetPalette, GetTiles and ShowFrame, then JumpBack to the first). The moved tables follow a header ("PK", how many, each one's kind: small walker or flier), which the randomizer reads to add them to its kinds; the 16-palette and VRAM check counts them as any type.

- **NiDL's swarm** (USA addresses): 115 pink Kirbys run, walk, float and tumble across the screen from the right after the HAL Laboratory / Nintendo logo. It's data: `0x080CAA3C` sets each up from `0x08757440` (script, delay, x, y; the draw order is 15 - ((y - 1) >> 4)), and `0x080CAAB8` runs them every frame. After its delay a Kirby runs commands of its script (`0x087577D8`, by index), 14 bytes each: a mask, then 6 slots (velocity x and y, acceleration x and y, frame, delay; 8.8 pixels), the slots whose bit (`0x01`-`0x20`) is set taken; `0x40` plays the sound in slot 0, `0x80` calls script slot 0, `0x100` jumps to it, `0x200`/`0x400` loop (slot 0 the count, forever when 0), `0x800` restarts the script, `0x1000` returns, `0x2000` ends the Kirby. Commands run until one sets a delay. Then velocity += acceleration, position += velocity, and a Kirby with a frame is drawn there (frame table `0x087554B8`: one 32x32 sprite each, 16 pixels up and left, from NiDL's 2D sprite sheet, some flipped), ending off the screen. NiDL's logo script plays sound `0x10D` (the crowd) 129 frames in, turns its title's background on at 164 and wipes the logo away behind the swarm from 185 to 271. The first Kirby's running steps are sound `0x9C`.
- **Found in the NiDL ROM by its code** (the data moves between regions, and the European entries differ a little): the setup by its loop's end (`cmp r5, #114; ble`) and its literals (entries `+0x68`, scripts `+0x70`, count `+0x5C`), the frame table from the update (`+0x288`), the sprite sheet's two LZ77 blobs (the left and right 16 tiles of each row) from the graphics load script (`0x02020000, 0x00400003, 0x02020000`), and the Kirby palette from the literal before the code loading it (`0xB530 0x1C05 0x205C 0x223E`). The 32x32 poses (55, the leading run of the frame table) are copied as 16 tiles each in 1D order.
- **In KatAM** (`title.c`): KatAM's intro (`sub_08145B64`, LogoEnd's only call, detoured to `CreateNidlTitle`) is replaced: KatAM's logo stays up and the swarm runs over it, frame for frame as NiDL's (checked against NiDL's sprites), drawn with KatAM's OAM slots (`sub_08156D84`) in palette 15. At frame 210, when the swarm covers most of the screen, KatAM's own title screen starts under it (`CreateTitleScreen`; KatAM's logo and title share VRAM, so there's no wipe), its fade from white leaving the sprites out. A, B or Start before then skip to the title, as NiDL's waits do. The swarm ends with its last Kirby, when the title screen's task is gone, or when it takes A or Start (after its 0x4A frames). NiDL's `0x9C` is KatAM's dash sound; `0x10D` is the stampede KatAM's own intro plays (`SE_INTRO_AMBIENT_2`, every 5 frames while 24 Kirbys or more are on the screen).
- **VRAM**: the European title screen's sprites take 416 tiles (the others' 28), so the 55 poses (880 tiles) don't fit beside them. At most 36 are on the screen at once, so they go through 36 slots (576 tiles): a pose takes the slot drawn longest ago (none this frame), loaded through KatAM's VBlank DMA queue (`gUnk_03002EC0`, as `bg.c`'s), so it changes when the frame's sprites show.
