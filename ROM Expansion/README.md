# ROM Expansion

Enemies, mini-bosses and copy abilities ported from *Kirby: Nightmare in Dream Land* into *Kirby & the Amazing Mirror*. `KatAMExpansion.cs` applies them. Every version of KatAM works (USA `B8KE`, European `B8KP`, Japanese revision 1 `B8KJ`), with the NiDL ROM of the same region: USA (`A7KE`), European (`A7KP`) or Japanese (`A7KJ`, *Hoshi no Kirby: Yume no Izumi Deluxe*). The NiDL ROMs hold the same data, the Japanese one's frame tables `0x3A8C` further and its descriptors at `0x08742DAC`, the European one's `0x23C7EC` further and at `0x0897B678`. NiDL addresses in these notes and the code are the USA ones.

European games show the enemies' English names in every language. Japanese games show none: their HP bar names are stored differently (not as the USA's per-type images), so the bar keeps type `0x31`'s own name.

## KatAM versions

The code is written against the KatAM decompilation, which builds the USA version. `build.sh` links it once per version: the USA build against `katam.elf`, the others against `versions/<version>.txt`, the same symbols' addresses in that version, found in its ROM by `find_symbols.py <katam decomp> <ROM> <symbols...>` (functions by their code with call targets and pointers masked, variables through the pointers in matched functions, and the rest by the shift of the nearest symbol found). The shift is only checked against the first bytes of the function, so check what it finds when it can't match a function by its code (Japan's `sub_08034E14` is `0x08034DD8`, found from the call in Mr. Frosty's code; the shift gave a similar function). The USA link also gets the decompilation's static functions the code calls (`--just-symbols` only takes global ones; `sub_0809D060`, the mini-boss defeat). Those tables also hold what `KatAMExpansion.cs` patches in each version (sprite tables, spawn and parameter tables, the hit flash branch, the HP bar name copies, the number of anims: 938 in the Japanese ROM, 939 in the others). When the code starts using a KatAM symbol the tables don't have, `build.sh` says so: rerun `find_symbols.py` with the full list for each version's ROM.

## How they fit in

KatAM treats object types `0x00`-`0x37` as enemies all over its code, and the only free one is `0x31`. So every ported enemy is type `0x31`, and the template's behavior byte picks which: high nibble = enemy (`NIDL_*` in `nidl.h`), low nibble = its variant. What the game reads per type is shared, so `nidl.c` handles it per enemy:

| Shared per type | How each enemy gets its own |
|---|---|
| Animations (`AnimInfo` table, indexed by the object's frame) | One table holding every enemy's frames; each enemy has its own range (`animBase`) and anim ID |
| Palette key | The type has none; each enemy loads its palette with its anim ID as the key |
| Hurt frames (indexes 0 and 1) | A generic 32x32 frame drawn from the last 16 tiles of the object's VRAM, where each enemy uploads its own hurt frame |
| HP bar name | The game's two name copies (`0x08034ED2`, `0x08035B34`) are patched to call `NidlCopyName` |
| Behavior start after a hit | `NidlStart` calls the enemy's own start |
| Gravity | The engine pulls every enemy down unless flag `0x40` is set (KatAM's flying enemies set it); `NidlStart` sets it, and each enemy moves up and down like in NiDL (`NidlFall` is the engine's gravity, for the ones that just stand or walk) |

Mini-bosses work the same way on object types `0x40`-`0x42` (`OBJ_EMPTY_40`-`42`), which KatAM already treats as mini-bosses everywhere (they're in every `ObjType38To42` check, and `gUnk_08352D80[type - 0x38]` is the mini-boss music): see Mini-bosses below.

The hit flash also looked the palette up again by type when it ended; its branch at `0x080857EE` is patched to keep the enemy's palette (which is what it found for the game's own enemies anyway).

## Files

- `nidl.h`, `nidl.c`: the shared part (creation, palette, hurt frame, names, NiDL's frame sequences, helpers like facing Kirby and stopping at ledges).
- `nidl_data.c`: `gNidlData`, left blank and filled in by `KatAMExpansion.cs` (names, and each enemy's `animBase`, anim ID and hurt frame).
- `abilities.h`, `abilities.c`, `abilities/*.c`: the new copy abilities (see Abilities below); `abilities/*.c` has one file per ability.
- `nidl_miniboss.c`, `minibosses/*.c`: the mini-bosses (types `0x40`-`0x42`): creation, the start of the fight, and one file per mini-boss.
- `enemies/*.c`: one file per enemy, written against the [KatAM decompilation](https://github.com/jiangzhengwenjz/katam) headers. NiDL runs enemies as coroutine scripts; each script is copied as tables of steps.
- `build.sh /path/to/katam`: compiles everything with the decompilation's `agbcc`, links it at `0x09000000` for each KatAM version and writes `../KatAMExpansionCode.cs` (each version's code, the symbols `KatAMExpansion.cs` uses and what it patches).
- `find_symbols.py`, `versions/*.txt`: the KatAM symbols' addresses in each version (see above).
- `../KatAMExpansionRooms.cs`: NiDL's rooms (see Rooms below); C# only, no code in the ROM.

## What `KatAMExpansion.AddEnemies()` writes into the KatAM ROM

The ROM is first padded from 16 MB to 32 MB with `0xFF` (the most the GBA maps: `0x08000000`-`0x09FFFFFF`, which emulators and flash carts load like any other ROM; the game saves to SRAM, so nothing else depends on its size). Everything new goes in that second half, so the expansion has 16 MB for its enemies and leaves the game's own free space to the randomizer.


| Where | What |
|---|---|
| `0x1000000` | Code, then the converted graphics, animations, names and the extended sprite tables |
| `gSpriteTables` (`0x3B909C`) | `anims`, `attrs` and `oamData` copied with more entries: anim `939` is the hurt frame, `940` on are the enemies (one variant per frame) |
| `gSpawnFuncTable1[0x31]` | `CreateNidlEnemy` |
| Object parameters (`0x351648 + 0x31 * 0x18`) | Hurt frames 0 and 1, Waddle Dee's score and HP, no ability, no palette key, VRAM for the biggest frame plus the hurt frame, `NidlStart`, the shared animations |
| `0x08034ED2`, `0x08035B34`, `0x080857EE` | The patches above |

Graphics come from the player's NiDL ROM: each enemy's descriptor (`0x0873EEA0 + (type - 8) * 4`: palette, LZ77 tiles) and frame table (8-byte OAM records). Nothing from NiDL is shipped.

## Mini-bosses

Ported mini-bosses are object types `0x40`-`0x42`; the behavior byte's high nibble picks the mini-boss (`NIDL_POPPY_BROS_SR`... in `nidl.h`), the low nibble its variant. An object's frame index is a byte, and the mini-bosses have more than 256 frames together, so they're spread over the three types, each with its own `AnimInfo` table (`0x40`: Poppy Bros. Sr., Mr. Tick-Tock, Grand Wheelie; `0x41`: Bugzzy, Fire Lion; `0x42`: the Meta-Knights); a mini-boss created with the other type's number becomes that type's first. KatAM's own Mr. Frosty, Bonkers and Phan Phan stay as they are (NiDL's are the same mini-bosses).

- **The fight** starts like KatAM's mini-bosses' (Mr. Frosty, `0x080CB7E8`): the mini-boss waits facing Kirby, untouchable, until Kirby is in the template's area (`unk1A`-`unk20`, the randomizer keeps the vanilla mini-boss's, or makes it the whole room for an enemy's spot, so the camera doesn't lock there), then the camera stays in that area (`Macro_081003EC`, which also copies its bounds into `unkA4`-`unkAA`; every frame `NidlUpdate` keeps the mini-boss's x inside them with `ObjXSomething`, as KatAM's mini-bosses do, and the Meta-Knights get Meta Knight's), the HP bar shows and the mini-boss music plays (`Macro_08100F18`). Defeat is KatAM's (the engine handles every type `0x38`-`0x52` the same way: it flies off, shows the frame after its second hurt frame, and explodes); its blink animation table (`gUnk_08D610B4`, by type - `0x38`) only had types `0x38`-`0x3F`, so it's copied with entries for `0x40`-`0x42` (none) and its one use points at the copy.
- **Shared per type**, as for the enemies: one `AnimInfo` table (its own, after the enemies'), each mini-boss's own palettes and anim ID, a 64x96 hurt frame (a 64x64 and a 64x32 piece, 96 tiles at the end of the object's VRAM, origin at its center; anim indexes 0, 1 and 2; type `0x42`'s is 32x64, 32 tiles, as several knights are out at once). A mini-boss can have several hurt frames (`NidlObject.hurt` picks one: each knight its own). A mini-boss too tall for it (Fire Lion) has its hurt frame and every frame drawn some pixels lower (`hurtShift`), and its hitbox and floor box as much lower (the engine resets `objBase55` after every frame it draws, so the sprite can't be moved back up), its own HP bar name. `NidlMinibossStart` (the type's start, after a hit too) sets the mini-boss's ability and calls its own start once the fight has started.
- **Graphics**: NiDL's mini-boss descriptors are at `0x0873F0E4 + index * 4` (USA; `region.Descriptors + 0x244` in every region; index = NiDL type - `0x31`), in the enemies' format, often with two palettes: frames drawn with the second load it under the anim ID | `0x2000`. Frame tables are the `0x0875xxxx` literal each spawn function stores at `obj+0x38`. Some frames are *streamed* (Mr. Tick-Tock's body): the table entry points to 12 bytes instead of OAM records, pointers to the frame's OAM records, its own palette (`u16 0x20`, then 16 colors) and its own tiles, which NiDL uploads with the frame (rows of VRAM, 32 tiles each: `u16` byte count and the tiles, until `0xFFFF`); `KatAMExpansion.PartPieces` reads both kinds.
- **Object types `0x40`-`0x42`'s parameters** are Mr. Frosty's (score, HP), with the hurt frames, no palette key, VRAM for the type's biggest frame plus the hurt frame, `NidlMinibossStart` and the type's animations; `gSpawnFuncTable1[0x40]`-`[0x42]` are `CreateNidlMiniboss`.
- **HP bar**: its fill is HP times `gUnk_08351458[type - 0x38][players - 1]` (the table right before `gUnk_08351648`), >> 8 (64 is full); KatAM has a placeholder (8192) for types `0x40`-`0x44`, which made the bar garbage, so the mini-boss types get Mr. Frosty's 546 (30 HP, as every ported mini-boss has).
- **Map tracker**: `KatAMExpansion.WriteMapTable` writes the last `0x100` bytes of the ROM: `NIDLMAP` and a version byte (1), then per mini-boss its type, index, name and an icon (its `Icon` frames, as 16-bit colors), which the map tracker reads to tell an expanded ROM and show these mini-bosses (`KatAM Map Tracker/Core/RomMap.cs`).
- **Randomizer**: with "Include mini-bosses" (ROM Expansion tab), types `0x40`-`0x42` join the mini-boss pool once per ported mini-boss of theirs, the behavior picking a mini-boss and then one of its variants.

## Abilities

NiDL's Needle, Freeze, Light, Ball, Hi-Jump, Mike and Backdrop are KatAM abilities 27-33 (`NIDL_ABILITY_*` in `abilities.h`). Needlous, Chilly, Cool Spook, Bubbles and Starman give the first five; Mike and Backdrop come from the mini-bosses Mr. Tick-Tock and Bugzzy.

| Ability | B button |
|---|---|
| Needle | Kirby sticks his needles out (10 frames) and keeps them out while B is held, then pulls them in. In the air he falls with needles all around, and keeps them out on landing if B is still held. The needles hurt what they touch (a cutting hit) and Kirby is unhurt while they're out |
| Freeze | Kirby wraps himself in ice crystals for as long as B is held (16 frames at least). What touches the ice freezes, with KatAM's Ice's freezing hit, and Kirby is unhurt meanwhile |
| Light | Kirby hovers and holds up a light (28 frames), which shines for 65 frames; then the ability is used up. NiDL's Light only lights up dark rooms. KatAM has none, so the light flashes the screen white (when the room isn't already blending) and hurts every enemy on the screen, like a weak Crash |
| Ball | Kirby hops (up to 20 pixels) and curls into a ball, which bounces once and then rests. B again launches it (up to 37 pixels), and it ends on landing. It can be steered in the air and hurts what it touches, Kirby unhurt meanwhile |
| Hi-Jump | Kirby crouches for 4 frames, then rockets up 4.16 pixels a frame for 25 frames or until he hits a ceiling, steerable sideways, hurting what he touches and unhurt; then he falls |
| Mike | Kirby sings, a different song each of the 3 times: into a megaphone, a microphone, then a microphone while jumping 26 pixels. While he sings, every enemy on the screen takes a heavy hit and the screen flashes. After the third song the ability is gone |
| Backdrop | KatAM's Throw (its closest relative: grab with a dash, then throw, a backdrop when thrown backwards) with NiDL's red headband: Throw's body draws its headband in colors 12-14 of the body palette, and Backdrop's palette has NiDL's red there. NiDL's own grab couldn't be measured (its Waddle Dee never came within reach) |

The timings and speeds were measured in NiDL. Mike and Backdrop were measured by patching the enemy Starman to give them: an enemy's ability is byte 12 of its variant data (Starman's: `0x08741918`), copied to `obj+0` of its extra data at spawn. In water, every ability's B button does what KatAM's other abilities do (the base ability's entry). CPU helpers fight like Normal Kirby.

How they fit in:

- **Ability field.** KatAM keeps the ability Kirby is getting in 5 bits of `transitioningAbility`, with 3 flags above it, so 27-31 were all the room there was. It's widened to 6 bits:
  - the "random" flag moves from `0x20` to `0x40`;
  - the old `0x40` flag ("several things in the mouth", which makes the spat star bigger) moves to `unkF1`, which the game only ever clears;
  - every `& 0x1F` read of the field becomes `& 0x3F` (18 places, found by their code, the same in every version);
  - swallowing (`sub_080547C4`) is replaced by `NidlSwallow`.
- **Ability tables.** Every table KatAM indexes by ability (B on land and in water, setup, body palette, hats, the CPU helpers' AI, the state after getting an ability, the pause world map's Kirby) is copied with 34 entries, and the game's code is pointed to the copies. The new entries come from `gNidlAbilityTables`, or from Normal's.
- **Swallowing.** `sub_080547C4` took abilities `0x1B` and `0x1C` to mean "random" and "none". They're now `0x3B` and `0x3C` (`NIDL_SWALLOW_*`), and the one object type whose ability was `0x1B` (`0xCE`) is changed to match.
- **HUD and pause portraits** are NiDL's ability cards. `sub_080356AC` and `sub_08088640` are detoured to `NidlAbilityPortrait` and `NidlAbilityHudTimer`, and the special portraits (`0x1C`-`0x1F`) move to `0x2C`-`0x2F`.
- **Hats** (`KatAMExpansionHats.cs`). KatAM draws Kirby as a body plus a hat sprite, animating in step. The new abilities use Normal's body table (`gUnk_0834C5D4`), and each one's hat anim has a variant per entry of it (185): the body's commands, with NiDL's hat for the same pose.
  - `BodyMatches` pairs each KatAM body frame with one of NiDL's plain Kirby poses, by silhouette, checked by eye. Mirrored body frames (attributes `| 0x4000` / `| 0x8000`) are matched unmirrored, and their hat is mirrored the same way.
  - `HatFrames` pairs each plain pose with the same pose in the ability's block. Its body pixels match exactly, or match outside the hat where the hat hides part of it.
  - Poses with no match (inhaling, a mouthful, Kirby facing the camera with something on his head) get no hat.
- **Attack poses** (`KatAMExpansionMotions.cs`) are NiDL's frames, played at animation indexes `0x4A`-`0x59` (copy abilities' own), which `NidlAbilitySetup` points to them.
  - Kirby's own pixels go to the body sprite, which has the player's palette and 16 tiles of VRAM.
  - The rest (ice, needles, the cape) goes to the hat sprite, which has 48 tiles of VRAM.
  - KatAM loads the hat sprite's palette from the ability's hat, so the poses use the colors that palette has free. Needle's hat leaves few, so its needles are a duller yellow than NiDL's.
- **Attacks** (`NidlAttackCreate`) are Burning's attack box: an object following Kirby while he's in the ability's state, with the hit's kind (`unk68`, as in `gUnk_082DDFC8`) and strength.

## Rooms

NiDL's level rooms (275, 285 KatAM rooms with the split ones) are converted from the player's NiDL ROM into KatAM's free room slots (rooms whose `gRoomProps` entry is all `0xFFFF`, ascending from 1), by `KatAMExpansionRooms.cs`, after the enemies and abilities ("Include rooms"). `KatAMExpansion.PortedRooms` lists which NiDL room became which KatAM room, `PortedDoors` their doors. Left out: the levels' hub lists (hub, museum, arena, boss tower, boss room: no gameplay of their own), level 7's stage 1 (the boss rush's copies of the boss rooms) and stage 2 (11 unused test rooms), the 7 placeholder 2x2 hub entries, and 3 empty 16x11 floors no exit leads to (levels 2 and 3's stage 5: `(2,5,6)`, `(3,5,2)`, `(3,5,6)`). The boss arenas (each level's last stage) and the Fountain of Dreams are kept, for the bosses to come.

- **NiDL's rooms** (the same data in every region, only the table moves: USA `0x087E1D58`, Japan `0x087E60DC`, Europe `0x08BFD8E8`): per level (0-7), 8 stage lists (`table + level * 0x20 + stage * 4`), then the levels' hub lists (`table + 0x100 + level * 4`: hub, museum, arena, boss tower, boss room). Each list holds room records (null where a room is missing) until one whose index (`+2`) isn't its place. A record: `+8` the cells (LZ77, `u32` per 16x16 cell: metatile, attribute, whose high byte is the collision), `+0xC` the breakable blocks' numbers (LZ77, `u16` per cell), `+0x10` the object data (a `u32` per block number: the metatile it leaves when broken, until `0xFFFFFFFF`), `+0x14` width, height (cells), `+0x18` the foreground (palette: `u16` byte count, then the colors, loaded at palette 2; LZ77 tiles at `0x06004000`; LZ77 metatiles, 4 tilemap entries each), `+0x28` the background (palette loaded at palette 8; LZ77 tiles; the map: `u16` byte count, width, height, then `0xFFFF` and the LZ77 map in GBA screenblock order (64x32), or the map row by row), `+0x34` the background's scroll rates (x, y, 16ths), `+0x44` the exits (12 bytes: room, 0, door x, y in cells, landing x, y), `+0x48` the objects (8 bytes: category + 1, index, variant, flags, x, y) up to the record itself, `+0x50` where Kirby starts.
- **Collision**: the high nibble is the kind (0, 5, 7 solid; 1 one-way floors, `0x10` a door; 2 breakable blocks; 3 ladders and climbing walls; 4 air currents; 6 spikes; 8 and C water; 9 water with one-way floors; E spikes in water), the low nibble the shape in NiDL's height maps (`0x087328F0`: empty, full, 45° and gentle floors, ceilings). `RoomCollision` maps each value to KatAM's (`gCollisionAttributes`): full `0x0D`, floors `0x0B`/`0x0C` (45°) and `0x05`-`0x08`, ceilings `0x01`-`0x04`, `0x09`, `0x0A`, one-way `0x0F`, `0x14`-`0x1B`, ladders `0x20`, `0x21`, spikes `0x1C`, water `0x48` and its slopes `0x34`-`0x43`, spikes in water `0x6D`. Breakable blocks become KatAM's special blocks (the solidity map's list: kind 1, value, x, y, the 4 tilemap entries left after, the collision left): star blocks `0xF0`, metal `0xF4` (NiDL `0x2D`), bomb blocks `0xF1` (`0x2E`) and the blocks they break `0xF2` (`0x2F`). Air currents are plain air for now.
- **Graphics**: the foreground tiles are NiDL's own LZ77 (it decompresses them to VRAM too), at KatAM's `0x06008000`; its palettes 2-7 are KatAM's 0-5, so every tilemap entry's palette goes down by 2; the metatiles become KatAM's 8x8 tilemap (LZ77). The background keeps only the tiles its map uses, renumbered: KatAM's HUD tiles follow the background's 900 (NiDL's backgrounds use exactly 900, one 944: past 900, tiles share the last one); its palettes 8-15 are KatAM's 6-13. It scrolls at NiDL's rates (`gRoomProps` `+0xE`, `+0x10`, 8.8).
- **Objects**: enemies in both games become KatAM's (Waddle Dee, Noddy, Pengy, Laser Ball, Sir Kibble, Waddle Doo, Gordo, Bronto Burt, Bomber, Shotzo (NiDL `0x19` and `0x2A`), Sparky, Twister, Squishy, Scarfy, Hot Head, Glunk, Blipper, Sword Knight, Flamer, UFO; NiDL's headband Waddle Dee is a Waddle Dee), the others the ported ones (type `0x31`, NiDL's variant as the behavior's low nibble); mini-bosses (category 1: 0 Bonkers, 3 Mr. Frosty, 7 Phan Phan, the rest ported) fight in the whole room; items (category 3: 1-Up, Maxim Tomato, Invincibility Candy, Energy Drink) become KatAM's 1UP, Maximum Tomato, Lollipop and Pep Brew. Bosses (category 2), gimmicks (4: warp stars...), big switches (5, 6) and Meta Knight's event (7) aren't ported.
- **KatAM's tables** (per version, `KatAMExpansionCode`'s `RomSymbols`): `gForegroundInfo`, `gForegroundPalettes`, `gForegroundTilemaps`, `gSolidityMaps`, `gRoomTiledBGs`, `gLevelObjLists`, `gUnk_08D63C28` (CPU helpers' zones: one zone per room) and `gUnk_08D640A4` (doors per `doorsIdx`) are copied with the new entries and every literal pointing at them repointed; `gRoomProps` and `gUnk_08D6CD0C` (per room: routes, area; area `0x0A` as KatAM's special rooms) get the new rooms in their free entries. Foreground tiles, palettes and backgrounds are shared between rooms as in NiDL. Song: one KatAM song per NiDL level. Flags `0x79` (as KatAM's own rooms: the phone works).
- **Limits**: a KatAM room has at most 1950 blocks (16x16): its collision, zones and tilemap buffers (`gUnk_02024ED0`, `gUnk_02026D60`, `gUnk_02028EE0`, one per player). The 7 bigger NiDL rooms are split along their longer side into parts that fit (each part its own KatAM room). Every new room uses `doorsIdx` 287, the one `gVisitedDoors` entry (`0x120` of them) no vanilla room uses.
- **Camera**: KatAM's camera keeps its view between (8, 8) and (width - 8, height - 40) (`unk_S32Vec2_6C`/`74`, set from the room's size when it loads): its rooms hide 40 pixels below what's seen, and 8 on the other sides. NiDL's don't, so each room gets its last row repeated 3 times below, and its last column and row repeated up to 16x13 cells (smaller rooms put the sprites' viewport off the room while the background stays on it, and the two drift apart). The padding's breakable blocks are solid (KatAM looks a breakable block's special block record up and would never find one). The splits count the padding.
- **Doors** (`PlanDoors`): KatAM's doors are a collision value (`gCollisionAttributes` with `0x4000`: `0xFF` a door, `0xFD` one in water; `0xFE`, `0xFC` an edge Kirby goes through as he touches it) and an 8ROM record in the room's special blocks (kind 3, the value, x, y, size 14, `0xFFFF`, `u16` room, x, y, facing (1 right, 2 left, `0x80` no respawn), `0xFF`): Kirby lands at x * 16 - 8, y * 16 - 7, so the record holds the landing cell + 1. KatAM also looks every door Kirby goes through up in the room's 9ROM list (`gUnk_08D640A4[doorsIdx]`: 8 bytes each, kind 2, size 8, `0xFFFF`, room, x, y; `0x0000FFFF` ends it) and loops until it finds it, so a door missing there hangs the game: every ported room shares `doorsIdx` 287 (the one `gVisitedDoors` entry no vanilla room uses), a list with every ported door's destination, whose count byte is 0 (the map counts none). A mirror (object `0x6F`, at the cell's center) stands on each door. They're made from NiDL's exits (12 bytes: room, kind, `u16` x, y, landing x, y in pixels):
  - kind 0, a door to a room of the same stage: where it was, to where it led;
  - kind 30, a warp star or cannon (x: the room): a mirror where the first warp star (gimmick 4) or cannon (6) stands, to where Kirby starts in that room (the exit's landing is where the flight starts, under the tower in Butter Building 3-2);
  - kind 34, the stage's goal door: to the next stage's start (where Kirby starts, `+0x50`, dropped to the floor);
  - kind 26, out of the room past its edge (x: the room, `0xFFFF` none; the sky Kirby falls from in 1-2, the towers he climbs out of): edges on the top and bottom rows' open cells;
  - kind 21, the secret doors to the hub's museum and arena: not ported;
  - the boss stages (each level's last, and the Fountain of Dreams) have no doors: each room gets a mirror where Kirby lands, to the stage's next room, then the next level;
  - a split room's parts lead into each other through the open cells on their shared edge (breakable ones too: Heavy Mole's arena is all blocks).
- **The way in**: Central Circle (`0x321`) gets a mirror on the left end of its platform (cell 11, 14) to Vegetable Valley 1-1, whose start has a mirror back, as has the Fountain of Dreams' last room. Central Circle's collision, objects, 8ROM and 9ROM list are what the randomizer writes, so `KatAMExpansion.FinishRooms` adds the door after it's done, into copies that table entries reserved by `AddRooms` point to; its 9ROM list keeps its count, so the map's doors don't change.
- **Not yet**: big switches (their rooms are connected, the switches aren't there), bosses, air currents, animated tiles and palettes, the museum signs' English text (the tiles are NiDL's Japanese ones).
